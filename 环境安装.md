### 1. 安装Java环境
```bash
sudo apt install openjdk-11-jdk -y

java -version
openjdk version "11.0.27" 2025-04-15
openJDK Runtime Environment (build 11.0.27+6-post-Ubuntu-0ubuntu124.04)
openJDK 64_Bit (build 11.0.27+6-post-Ubuntu-0ubuntu124.04, mixed mode, sharing)

which java
/usr/bin/java

vim ~/.bashrc
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
export PATH=$JAVA_HOME/bin:$PATH

source ~/.bashrc
```
### 2. 安装kafka
```bash
 wget https://dlcdn.apache.org/kafka/3.9.1/kafka_2.13-3.9.1.tgz
tar -xzf kafka_2.13-3.9.1.tgz
cd kafka_2.13-3.9.1
```
初始化初始化 Kafka 存储（使用 KRaft 模式，无需 Zookeeper）
```bash
bin/kafka-storage.sh format -t $(uuidgen) -c config/kraft/server.properties
```
启动 Kafka 服务
```bash
bin/kafka-server-start.sh config/kraft/server.properties
```
后台启动
```bash
root@worker02:/home/jeff/kafka_2.13-3.9.1# bin/kafka-server-start.sh -daemon config/kraft/server.properties
root@worker02:/home/jeff/kafka_2.13-3.9.1# lsof -i:9092

```
